# gh600-sandbox

Practice repository for the GH-600 video course labs.

- `app/` – a tiny inventory service (the code agents work on)
- `tests/` – unit tests, run with `python -m pytest -q`
- `docs/` – user documentation
- `lab-notes/` – your evidence and notes for every lab

This repository contains no secrets and must never contain any.
Refactored for clarity.
